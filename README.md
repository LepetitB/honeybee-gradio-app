# Honey Bee Species Classification

This is a Gradio app for classifying honey bee species from uploaded images.

## Files

- app.py: Gradio application
- best_model.pth: trained PyTorch model weights
- class_names.json: class labels
- model_config.json: model architecture and image size
- requirements.txt: Python dependencies
